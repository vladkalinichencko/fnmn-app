# Browser library export

[`browser_library.py`](../../mac/browser_library.py) собирает Safari Reading List, выбранные Safari Tab Groups и папки Dia в [`browser-library.json`](../../browser-library.json). Результат хранит один объект на конкретный источник, его существующую страницу-каталог, материалы и итоговые категории в `saved_in`. Поле `found_in` сохраняет реальные места исходных ссылок, включая конкретную Safari-группу. Сохранённый каталог без отдельных материалов остаётся источником с пустым `materials`. Если несколько закладок ведут на один материал через разные URL, `saved_urls` сохраняет каждый исходный адрес.

Источники определяются по устойчивой структуре URL. Substack связывается с каталогом публикации, Medium и X с автором, GitHub с репозиторием, MIT OpenCourseWare с курсом, Habr с компанией или автором. Сохранённые YouTube-плейлисты и видео со ссылкой на плейлист раскрываются через `yt-dlp`; отдельное видео без тематического плейлиста связывается с каналом. Подтверждённые каталоги персональных блогов, корпоративных разделов, изданий, курсов, проектов и документов записаны в [`browser_source_overrides.json`](../../mac/browser_source_overrides.json). Ошибки следующего запуска остаются в `review`.

К Safari добавлены четыре актуальные группы из `SafariTabs.db`: 47 URL из `best render engines learning content`, 32 из `Self-studу`, 22 из `research blog posts` и 5 из `UI History`. Пустые Start Page и служебные узлы Safari не экспортируются. Render Engines и Self Study распределяются по Theory Sources и Theory Videos по типу URL, Research Blog Posts входит в Theory Sources, UI History — в UX/UI. Дедупликация выполняется вместе с Reading List и Dia, а не отдельно для каждой группы.

Текущий экспорт охватывает 489 исходных записей и 476 уникальных URL. После объединения повторов и раскрытия плейлистов в нём 344 источника и 937 вложенных материалов; 68 сохранённых страниц сами являются источниками. В `review` и `errors` нет записей.

Tab Groups Dia не входят в результат. [`dia-local-sources.md`](dia-local-sources.md) фиксирует, что их локальные базы не читаются как SQLite или JSON. Для добавления групп нужен экспорт URL из интерфейса Dia или отдельный доступ к живому внутреннему API.
