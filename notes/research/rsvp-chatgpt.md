# RSVP: разговор с ChatGPT

Разговор о том, работает ли быстрое чтение по слову и как сделать RSVP, который не теряет понимание: [общая ссылка](https://chatgpt.com/share/6ac00888-ea90-83e9-8a03-34861679d3eb). Это чужой анализ: ссылки на работы и приложения в нём не проверялись здесь. Проверенные данные и выбор режимов лежат в [speed-reading.md](speed-reading.md). Требования к режиму собраны в задачах [M3](../tasks.md#m3-быстрое-чтение).

| Утверждение из разговора | Оценка |
|---|---|
| RSVP показывает слова по одному в фиксированной точке, иногда с цветной опорной буквой; 200 слов в минуту для него медленно, интерес начинается с 350–500 | Совпадает с описанием технологии; пороги скорости надо проверить по работам |
| Запрет возвратов глазами ухудшает понимание; при 700–1000 слов в минуту понимание хуже, чем при статичном тексте | Правдоподобно, ссылки не открыты; проверяется в speed-reading.md |
| Для облегчения понимания лучше пауза между предложениями или повтор предложения, чем равномерное замедление (Rahman и Muter, 1999) | Работа не проверена; идея ложится на задачу повтора предложения |
| Читалки с раздельными паузами на знаках, чанками по 2–3 слова, полупрозрачными соседними словами и быстрым повтором последнего предложения (Strobe, Outread, SwiftRead) | Описание продуктов с чужих слов; как набор приёмов подходит для M3 |
| «Правильный» RSVP: 400–600 слов в минуту внутри предложения, пауза после точки и абзаца, трудные слова дольше, повтор предложения, удержание показывает абзац, после абзаца он показывается целиком на секунду-две | Конкретные числа не обоснованы измерениями; берём как стартовые настройки, которые можно менять |
| Показ целого абзаца после прохода возвращает пространственную картину; режим «каждый абзац дважды» не исследован | Гипотеза без измерения; станет флагом настроек, сравнивать по возвратам |
| Адаптивный RSVP: модель оценивает сложность предложения и решает темп, паузу и второй проход | Идея, которая зависит от оценки сложности из M5; в M3 только место под неё |
| Для математики и научных статей обычное чтение почти наверняка лучше; RSVP годится для первого прохода и простого текста | Согласуется с нашим материалом: формулы и код в RSVP останавливают поток |
