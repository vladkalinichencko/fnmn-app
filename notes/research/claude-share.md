# Claude share

Публичная ссылка вида `https://claude.ai/share/<uuid>`. Адаптер `server/adapters/claude.py` читает разговор из `https://claude.ai/api/chat_snapshots/<uuid>?rendering_mode=messages&render_all_tools=true` через `web.text` и отдаёт Markdown с ролями User и Assistant, как ChatGPT. Cloudflare отвечает на обычный запрос сервера страницей проверки, поэтому при отказе тот же адрес открывается через `web.rendered` в обычном Chrome, и JSON берётся из `<pre>`, в котором Chrome показывает ответ API. Живой разговор этим путём ещё не прочитан: публичной ссылки на Claude-разговор в репо нет.

Проверено 2 октября 2026 года.

## Что видно снаружи

Страница `https://claude.ai/share/<uuid>` отвечает `200` и отдаёт только оболочку приложения на 128 КБ. В `og:title` стоит «Claude», сообщений в HTML нет, поэтому разбирать страницу, как у ChatGPT, нечего. Встроенный скрипт оболочки берёт uuid из пути и, если у зрителя нет сессии, сам запрашивает `/api/chat_snapshots/<uuid>?rendering_mode=messages&render_all_tools=true` с `credentials: "include"`. Значит, адрес API и его параметры совпадают с тем, что открывает браузер, и это видно в коде страницы, а не взято из догадки.

Тот же API на запрос через `Web` (httpx, User-Agent `FNMN/1.0`) ответил `403 Forbidden` с заголовками `server: cloudflare`, `cf-mitigated: challenge` и HTML «Just a moment...». Запрос был один, повторов и обходов не было. В импорте это превращается в `ImportFailure("fetchingPage", "Client error '403 Forbidden' ...")`.

## Форма ответа, на которую рассчитан разбор

Форма снята по описанию API, а не с живого ответа: `snapshot_name` даёт название, `chat_messages` даёт список сообщений с `sender` (`human` или `assistant`), списком блоков `content` и старым полем `text`. Тесты собраны на JSON этой формы.

Остаются текстовые блоки обеих сторон. Если `content` пуст или его нет, берётся `text`. Формулы проходят через ту же нормализацию, что у ChatGPT: `$$…$$` и `$…$` остаются как есть, редкие `\[…\]` и `\(…\)` превращаются в них же.

Артефакт приходит как блок `tool_use` с именем `artifacts`. Markdown встаёт в текст, а его заголовки опускаются на два уровня, чтобы не спорить с `#` названия и `##` ролей. Код (`application/vnd.ant.code`) идёт в fenced-блок с языком из `language`, React (`application/vnd.ant.react`) идёт кодом `jsx`, Mermaid идёт блоком `mermaid`. Ограда берётся на один бэктик длиннее самой длинной серии внутри кода. HTML и SVG становятся страницей `assets/interactive-<hash>.html` и блоком `fnmn-interactive`, как сгенерированное приложение ChatGPT. Цельный HTML-документ кладётся как есть, а фрагмент и SVG оборачиваются в минимальную страницу. Команда `update` применяет `old_str` → `new_str` к прошлой версии с тем же `id`, `create` и `rewrite` берут `content` целиком. Каждая команда показывает артефакт в том виде, какой он после неё, поэтому правленый код встречается в тексте столько раз, сколько Claude его менял.

Выкидываются блоки `thinking`, все `tool_result`, любые `tool_use` кроме `artifacts` (поиск, web_fetch, исполнение кода), цитаты к тексту, вложения и картинки пользователя.

## Открытые риски

1. **Cloudflare.** API отвечает прямому запросу `cf-mitigated: challenge`, и импорт держится на Chrome. Если Cloudflare не выпустит и обычный Chrome без сессии, импорт упадёт с `ImportFailure("fetchingPage", …)`, где названы обе причины. Не проверено, проходит ли Chrome проверку за десять секунд ожидания `_rendered`.
2. **Форма JSON не сверена с живым ответом.** Если у сообщений есть ветки (`parent_message_uuid`), а `chat_messages` содержит больше одной ветки, адаптер покажет их подряд. Новые инструменты Claude для файлов (`create_file`, `present_files`) сейчас выкидываются как служебные, хотя могут нести видимый результат.
3. **React-артефакты не запускаются.** Им нужны React, Tailwind, lucide и компоненты shadcn, которых в странице читалки нет, поэтому они показаны кодом.
4. **Приложение классифицирует `claude.ai` как обычную веб-ссылку.** `CaptureRoute` в Swift использует источник только как проверку, что ссылка веб-адрес, а адаптер выбирает сервер. Поэтому общий `fixtures/capture-sources.json` строку для Claude не получил: Swift-тест на нём ждал бы `web`.
