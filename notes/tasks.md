# FNMN: очередь работ

Файл идёт сверху вниз: milestone (`##`), тема (`###`), задача, подзадачи вложены отступом. Milestone задаёт крупную возможность приложения и порядок, в котором они наращиваются: каждый следующий опирается на данные и интерфейс предыдущего. Закрытые задачи остаются на месте.

| Milestone | Что появляется | Статус |
|---|---|---|
| [M1](#m1-читатель-и-библиотека) | Библиотека, импорт с Mac, читатель плашками, заметки, прочитанное | готов |
| [M2](#m2-плашки-как-единица-текста) | Плашка как самостоятельная единица: по одной на экран, свои фрагменты | следующий |
| [M3](#m3-быстрое-чтение) | Режимы, где текст идёт за читателя: RSVP, подсветка, темп | |
| [M4](#m4-основа-платформы) | Шрифты, виджеты, поиск по всему, Mac, синхронизация без Mac | параллельно остальным |
| [M5](#m5-ии-разметка-и-мета-харнес) | ИИ помечает, что можно не читать; правила и память в мета-харнесе | |
| [M6](#m6-переписывание-текста) | Операции онтологии над плашкой: делить, сокращать, объяснять, проверять | |
| [M7](#m7-лента-постов) | Вкладка с лентой: пост — один факт, треды, реакции, задания | |
| [M8](#m8-адаптивная-лента) | Правила запоминаются и меняются по реакциям и комментариям | |
| [M9](#m9-мультимодальность) | Визуализации, озвучка, видео, внешние источники | |
| [M10](#m10-дайджест-соцсетей) | Сервер следит за X и Telegram, дважды в день готовит журнальную вкладку; классификатор на телефоне | в работе |

Замысел мета-харнеса лежит в [design/meta-harness.md](design/meta-harness.md), правила редактирования в [design/editing-ontology.md](design/editing-ontology.md), ходы тьютора в [design/tutor-moves.md](design/tutor-moves.md).

## M1. Читатель и библиотека

Библиотека, подготовка материала на Mac, чтение плашками, выделения, заметки на полях, прочитанное и красная линия, видео с транскриптом, синхронизация через папку FNMN в iCloud.

## M2. Плашки как единица текста

Плашка уже держит абзац, место чтения и заметку. Здесь она становится единицей, с которой работают дальше: читается по одной, делится на мысли, прячет лишнее. Всё, что ИИ позже сделает с текстом (M5, M6), опирается на модель плашки и на ссылку «откуда это взято», поэтому они появляются раньше любого ИИ и вручную.

Листается по вертикали: тянешь дальше конца плашки и отпускаешь — следующая, дальше начала — предыдущая. Шаг вперёд засчитывает оставленную плашку прочитанной: с красной линией линия встаёт на верх новой плашки, как «Read to Here», шаг назад возвращает её на верх показанной; без линии место чтения идёт за плашкой и сохраняется через `savePlace`, как при прокрутке (`ReaderAction.turnPlate`).

## M3. Быстрое чтение

Режимы, в которых текст идёт за читателем: слово в одной точке, бегущая указка по плашке. Порядок по исследованию: RSVP, подсветка по месту, затем одна плашка на экран из M2; подсветка начала слов (Bionic Reading) выигрыша в проверках не показала и откладывается. Подробное исследование: [speed-reading.md](research/speed-reading.md); разговор, с которого всё началось: [rsvp-chatgpt.md](research/rsvp-chatgpt.md). Первая версия RSVP нужна не для рекорда скорости, а как режим принудительного темпа, из которого можно вернуться на страницу в любой момент.

- [x] Исследование режимов быстрого чтения и их настроек: [speed-reading.md](research/speed-reading.md). RSVP включаемым режимом, а не заменой чтения: у обычных читателей единственное прямое измерение показывает потерю буквального понимания, у студентов с СДВГ есть одна небольшая работа с обратным результатом.
- [x] RSVP (`SpeedReader`): пункт «Speed Reading» в меню `···` открывает на весь экран слово в одной точке, начиная с места чтения (с красной линией — с её блока и доли). Вверху раздел, тонкая полоса прогресса и «42% · 12 min left»; внизу большая кнопка Play/Pause, назад и вперёд на предложение, скорость от 150 до 600 с шагом 25 (по умолчанию 250, выше 300 подпись, что понимание падает). Открывается на паузе, чтобы сначала увидеть, где ты; касание слова тоже запускает и останавливает. Блокировка экрана или уход из приложения ставит на паузу. Токены, паузы, кадры, опорная буква, переход по предложениям и минуты до конца — `SpeedText` в FNMNCore с тестами; настройки в `@AppStorage` (`ReaderAppearance.speedKey` и соседние).
  - [ ] Раздельные паузы: запятая, точка, двоеточие, тире, абзац, числа, длинные и редкие слова.
