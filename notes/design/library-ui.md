# FNMN: библиотека и просмотрщик

Статус: проект интерфейса для согласования. Он описывает текущий этап: добавление материалов, поиск, чтение и связь с Mac. Код пока оставляет отдельную вкладку Search и поля сервера внутри Add; схема ниже предлагает изменить это. Учебная лента и посты описаны отдельно в [SPEC.md](../../SPEC.md) и не влияют на эти экраны.

## Главный экран

```text
iPhone                               iPad, любое окно
Library                   +  ···      Library sidebar       │ Material
Search library                        Search library        │ Reader
Continue                              Continue              │
Folders                               Folders               │
All materials                         All materials         │
Library           Shelf               Library / Shelf       │
```

На iPhone остаются две вкладки: Library и Shelf. На iPad Library использует системный `NavigationSplitView`: список слева, выбранный материал справа; при сужении окна система сворачивает колонки. У каждого окна собственные выбранный материал, вкладка и поисковый запрос. `+` находится в панели Library; `···` открывает Mac connection и действия управления библиотекой. Shelf сохраняет заметки, выделения, прочитанное и архив и открывает выбранный материал в этом же окне.

## Где находится поиск

| Место | Что ищет | Когда появляется |
|---|---|---|
| Library, верх списка или боковой панели | Материалы по названию, автору, папке и заголовку раздела | Сейчас. Отдельная вкладка Search убирается после согласования этой схемы. |
| Shelf, верх списка | Заметки и выделения по тексту; фильтры Notes, Highlights, Read и Archive остаются видимыми | Следующий проход по интерфейсу просмотрщика. |
| Панель читателя, кнопка Search | Текст открытой статьи или книги; у видео текст и время реплики | После реализации индекса текста. До этого кнопку не показывать. |

Глобальный поиск по тексту всех книг требует отдельного индекса. Результат не должен выглядеть как полный поиск, пока приложение проверяет только метаданные. Поиск внутри папки использует тот же Library search с фильтром выбранной папки, без второго самостоятельного поля.

## Добавление

Нажатие `+` открывает лист Add. Вверху одно поле `Link` и кнопка `Prepare`. Ниже стоят `Import prepared file` для готового JSON-пакета и `Import book folder` для проверенного каталога книги. Кнопки сырого PDF пока нет: текущий Mac API принимает ссылку и возвращает готовый пакет, но не принимает файл PDF с телефона. При появлении загрузки файла она войдёт в тот же лист отдельным действием `Send PDF to Mac`.

Под полем ссылки показывается краткий статус Mac: `Connected`, `Mac unavailable` или `Connection needs attention`; нажатие открывает Mac connection. Недоступный Mac не блокирует импорт готового файла и чтение сохранённой библиотеки. При ошибке введённая ссылка остаётся в поле. После подготовки приложение показывает выбор папок, затем открывает добавленный материал. Закрытие листа во время подготовки оставляет операцию и Live Activity; результат возвращается в то окно, где её начали.

## Mac connection

Сейчас вход находится в панели Library и в Add: `Mac connection`. Экран сохраняет адрес Mac и токен, затем кнопка `Save and check connection` выполняет авторизованный запрос. Основной кандидат — Tailscale Funnel на Mac: FNMN получает обычный HTTPS-адрес `https://<Mac>.<tailnet>.ts.net`, который работает без Tailscale-клиента на телефоне и при включённом другом VPN, если тот пропускает этот адрес. Funnel открывает вход в API публично, поэтому каждый рабочий запрос проверяет отдельный токен сервиса. Адрес и токен задаются один раз и не повторяются в каждом Add; токен хранится в Keychain. Этот путь нужно проверить на реальном телефоне с VPN и без него.

`Save and check connection` обращается к `/health` с bearer-токеном; при ошибке сохраняет настройки и показывает ответ сервиса или ошибку сети. Использование другого защищённого HTTPS-маршрута меняет настройку адреса, но не путь пользователя по экрану Add. [Проверенные варианты транспорта](../research/remote-mac-access.md).

## Чтение и границы данных

Панель читателя оставляет `Sections`, `Text` и `Source`; поиск текущего документа добавляется после индекса. Библиотека, готовые статьи и книги остаются на iPhone/iPad и открываются без Mac. Mac нужен для подготовки новой ссылки или сырого файла. Текущий ответ `/articles` содержит пакет и файлы в одном JSON; передачу больших PDF надо проектировать отдельно с проверкой размера, времени ожидания и возобновления передачи.
